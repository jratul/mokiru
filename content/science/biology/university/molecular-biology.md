분자생물학은 생명 현상을 분자 수준에서 탐구한다. [고등 생물](/science/biology/high)에서 배운 멘델 유전법칙이 어떻게 DNA 서열로 구현되는지, [생화학](/science/biology/university/biochemistry)의 단백질이 어떻게 만들어지는지를 설명한다. [물리화학](/science/chemistry/university/physical-chemistry)의 X선 회절로 DNA 이중 나선이 발견되었고, [정보이론](/math/ai-math/information-theory)의 코드 개념이 유전 암호와 정확히 대응된다.

## DNA 구조

### 왓슨-크릭 이중 나선 모델 (1953)

로절린드 프랭클린의 X선 회절 사진을 바탕으로 왓슨과 크릭이 구조 확립.

**주요 특징**:
- 두 가닥이 **반평행(antiparallel)**: 한 가닥은 5'→3', 다른 가닥은 3'→5'
- **염기 쌍**: A-T (2개 수소결합), G-C (3개 수소결합)
- 당-인산 골격(backbone)이 외부, 염기가 내부(소수성 환경에서 안정)
- 우향 나선(B형 DNA): 직경 2 nm, 피치 3.4 nm, 10 염기쌍/회전

**샤가프의 규칙(Chargaff's rules)**: $[A] = [T]$, $[G] = [C]$

### 뉴클레오타이드 구조

뉴클레오타이드 = 인산 + 5탄당 + 질소 염기

**퓨린(Purine)**: 아데닌(A), 구아닌(G) — 이중 고리

**피리미딘(Pyrimidine)**: 사이토신(C), 타이민(T), 유라실(U) — 단일 고리

### DNA vs RNA

| 특징 | DNA | RNA |
|------|-----|-----|
| 당 | 2'-디옥시리보스 | 리보스 |
| 염기 | A, T, G, C | A, **U**, G, C |
| 구조 | 이중 나선 | 단일 가닥 (다양한 구조 가능) |
| 기능 | 유전 정보 저장 | 유전 정보 전달, 번역, 효소 |
| 안정성 | 안정 | 불안정 (2'-OH로 인해 가수분해) |

## 중심 원리 (Central Dogma)

$$
\text{DNA} \xrightarrow{\text{복제}} \text{DNA} \xrightarrow{\text{전사}} \text{RNA} \xrightarrow{\text{번역}} \text{단백질}
$$

역전사(Retrovirus): RNA → DNA (HIV 등)

## DNA 복제

### 반보존적 복제 (Semiconservative Replication)

각 딸 DNA는 원래 가닥 1개 + 새로 합성된 가닥 1개.

**메셀슨-스탈 실험(1958)**: ¹⁵N→¹⁴N 전환 후 밀도 기울기 원심분리로 증명.

### 복제의 분자 기구

1. **개시**: 복제 원점(origin of replication)에서 시작. 진핵생물은 여러 개.
2. **풀기**: 헬리케이스(Helicase)가 이중 나선 풀기. SSB 단백질이 단일 가닥 유지.
3. **RNA 프라이머**: 프라이메이즈(Primase)가 짧은 RNA 프라이머 합성 (DNA 중합효소는 프라이머 필요).
4. **신장**: DNA 중합효소 III (원핵)가 **5'→3' 방향**으로 합성.
   - **선도 가닥(leading strand)**: 연속 합성
   - **지연 가닥(lagging strand)**: 불연속 합성 (오카자키 단편)
5. **완성**: 프라이머 제거 → DNA 중합효소 I가 갭 채움 → DNA 리가아제 단편 연결.

**복제의 정확성**: DNA 중합효소의 3'→5' 교정 활성 → 오류율 $10^{-9}/\text{bp}$

## 전사 (Transcription)

### 개요

DNA 주형으로부터 mRNA 합성. RNA 중합효소가 담당.

**개시**: 프로모터(-10, -35 영역) 인식 → RNA 중합효소 결합.

**신장**: 5'→3' 방향으로 RNA 합성 (DNA 주형은 3'→5' 읽음).

**종결**: 종결 서열 또는 로(ρ) 인자에 의해 종결.

### 진핵생물의 전사 후 가공

**5' 캡**: 7-메틸구아노신 추가 → 리보솜 인식, mRNA 분해 방어.

**폴리A 꼬리**: 3' 말단에 150~200개 아데닌 추가 → mRNA 안정성.

**RNA 스플라이싱(Splicing)**: 인트론(비코딩) 제거, 엑손(코딩) 연결.

스플라이소솜(Spliceosome): snRNA + 단백질 복합체.

**대안 스플라이싱(Alternative Splicing)**: 같은 유전자에서 다른 단백질 생산 가능. 인간 약 2만 개 유전자 → 약 10만 개 이상 단백질.

## 번역 (Translation)

### 유전 암호 (Genetic Code)

- 트리플렛 코돈(triplet codon): 3개의 뉴클레오타이드 = 1개의 아미노산 지정
- 64가지 코돈 → 20가지 아미노산 (코돈 축퇴성: degeneracy)
- **시작 코돈**: AUG (메티오닌)
- **종결 코돈**: UAA, UAG, UGA (아미노산 없음)

### tRNA의 구조와 기능

- **안티코돈(anticodon)**: mRNA 코돈에 상보적 결합
- **아미노산 결합 부위**: 3' 말단의 CCA

**아미노아실-tRNA 합성효소(aaRS)**: tRNA에 정확한 아미노산 결합 — 번역의 정확성 핵심.

### 리보솜과 번역 과정

리보솜: 소단위체 + 대단위체. 원핵(70S = 30S + 50S), 진핵(80S = 40S + 60S).

리보솜의 3 결합 부위: A (아미노아실), P (펩티딜), E (이탈).

**개시 → 신장 → 종결**:

신장 단계:
1. 코돈 인식: aminoacyl-tRNA가 A 부위에 결합
2. 펩타이드 결합 형성 (리보자임 활성!)
3. 전좌: 리보솜이 mRNA를 3' 방향으로 이동

폴리솜(Polysome): 하나의 mRNA에 여러 리보솜 동시 번역 → 효율↑

## 유전자 발현 조절

### 원핵생물: 오페론 모델

**lac 오페론** (젖당 분해):

- 젖당 없음 + 포도당 있음: 억제 단백질 작동자 결합 → 전사 억제
- 젖당 있음 + 포도당 없음: cAMP-CAP 활성화 + 억제 단백질 해제 → 전사 활성화

이중 조절: **억제 조절** + **활성화 조절** → 에너지 효율 극대화.

### 진핵생물의 조절

**전사 전 수준**:
- **히스톤 아세틸화**: 크로마틴 열림 → 전사 촉진
- **DNA 메틸화**: 유전자 침묵
- **후성유전학(Epigenetics)**: DNA 서열 변화 없이 유전자 발현 변화

**전사 수준**:
- **전사 인자(Transcription Factors)**: 프로모터·인핸서에 결합
- 인핸서: 유전자와 멀리 떨어져 있지만 루프 형성으로 프로모터 활성화

**전사 후 수준**:
- miRNA: 짧은 비코딩 RNA가 mRNA에 결합 → 번역 억제 또는 분해
- mRNA 안정성

## 유전공학

### CRISPR-Cas9

**Cas9**: 특정 DNA 서열 자르는 분자 가위.

**가이드 RNA(gRNA)**: 표적 DNA 서열 지정.

**응용**:
- 유전 질환 치료 (겸형 적혈구 빈혈증, 근이영양증)
- 암 치료 (면역 세포 편집)
- 농업 (질병 저항성 작물)
- 기초 연구 (유전자 기능 규명)

## 연습문제

**문제 1.** DNA 주형 가닥이 3'-ATCGTA-5'일 때, mRNA 서열을 써라.

> **풀이**
>
> RNA 중합효소는 DNA 주형 가닥의 3'→5' 방향을 읽어 5'→3' mRNA 합성:
>
> DNA 주형: 3'-A T C G T A-5'
>
> mRNA: 5'-**U A G C A U**-3'
>
> (A→U, T→A, C→G, G→C)

---

**문제 2.** 반보존적 복제를 증명한 메셀슨-스탈 실험을 설명하여라.

> **풀이**
>
> 1. 대장균을 무거운 질소($^{15}$N)에서 배양 → 모든 DNA가 무거움 (¹⁵N-¹⁵N)
> 2. 가벼운 질소($^{14}$N)로 옮겨 **1회** 분열 후 원심분리 → **중간 무게** 밴드 1개 (¹⁵N-¹⁴N)
> 3. **2회** 분열 후 → 중간 무게 + 가벼운 무게 밴드 (1:1)
>
> 반보존: 각 딸 DNA가 원래 가닥 1개 + 새 가닥 1개 → 1회 분열 후 모두 ¹⁵N-¹⁴N.
>
> 보존적이었다면: 무거운 + 가벼운 (1:1). 분산적이었다면: 1회 분열부터 두 밴드.

---

**문제 3.** mRNA 코돈 5'-AUG-UCA-CGG-UAA-3'를 번역하면 어떤 폴리펩타이드가 만들어지는가?

> **풀이**
>
> AUG = 메티오닌(Met) — 시작 코돈
>
> UCA = 세린(Ser)
>
> CGG = 아르기닌(Arg)
>
> UAA = 종결 코돈 (번역 종료)
>
> 폴리펩타이드: **Met-Ser-Arg** (3개 아미노산, N-말단 메티오닌)

---

**문제 4.** 대안 스플라이싱의 생물학적 의의를 설명하여라.

> **풀이**
>
> 하나의 유전자에서 엑손을 다양하게 조합하여 여러 종류의 mRNA → 여러 종류의 단백질 생산.
>
> 인간 게놈에는 약 2만 개 단백질 코딩 유전자 → 대안 스플라이싱으로 수십만 종류 단백질 가능.
>
> **예**: 트로포닌 유전자 — 심근과 골격근에서 다른 형태로 스플라이싱 → 근육 특이적 단백질.
>
> 따라서 "유전자 1개 = 단백질 1개" 관계는 더 이상 성립하지 않는다.
