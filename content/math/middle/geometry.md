기하(geometry)는 그리스어 "geo(땅)와 metron(측정)"에서 왔다. 기원전 이집트에서는 나일강 홍수 후 땅의 경계를 다시 측량하기 위해 기하학이 발달했다. 피라미드를 짓고, 별자리로 항해하고, 다리와 건물을 설계하는 것 — 모두 기하 없이는 불가능했다.

기하는 도형의 성질을 논리적 추론으로 밝히는 수학이다. 그리스 수학자 유클리드는 몇 가지 기본 공리에서 출발해 수백 가지 정리를 증명했다. "피타고라스 정리"처럼 외워서 쓰는 것이 아니라, 왜 성립하는지 논리적으로 이해하는 것이 기하의 목표다.

여기서 배우는 합동·닮음·피타고라스 정리는 [고등 기하](/math/high/geometry)의 벡터·좌표기하, [대학 선형대수학](/math/university/linear-algebra)의 내적·거리, [대학 미적분학](/math/university/calculus)의 곡선 길이 계산으로 이어진다.

## 기본 도형

### 점, 선, 면

유클리드 기하의 출발점은 "정의될 수 없는" 기본 개념들이다.

| 개념 | 설명 | 수학적 의미 |
|------|------|-----------|
| **점** | 위치만 있고 크기는 없다 | 차원이 0 |
| **선** | 점이 움직인 자취. 길이만 있고 폭은 없다 | 차원이 1 |
| **면** | 선이 움직인 자취. 넓이만 있고 두께는 없다 | 차원이 2 |

현실의 "점"은 크기가 있고, "선"은 폭이 있다. 수학에서의 점·선·면은 이상적인 추상 개념이다.

### 직선, 반직선, 선분

같은 두 점이 있더라도 어디까지 연장하느냐에 따라 세 가지로 나뉜다.

- **직선** $\overleftrightarrow{AB}$: 두 점을 지나며 양쪽으로 끝없이 연장. 유한한 길이가 없다.
- **반직선** $\overrightarrow{AB}$: 점 $A$에서 시작해 $B$ 방향으로 한쪽만 연장. 시작점은 있지만 끝점은 없다.
- **선분** $\overline{AB}$: 두 점 사이의 유한한 부분. 시작점과 끝점이 모두 있다.

두 점이 주어지면 직선은 **하나**, 반직선은 **두 개** (방향에 따라), 선분은 **하나** 결정된다.

선분의 길이는 [함수](/math/middle/function) 단원에서 좌표로 다음과 같이 계산한다:
$$AB = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2}$$

### 각의 종류

**각** $\angle AOB$: 꼭짓점 $O$에서 나온 두 반직선 $\overrightarrow{OA}$와 $\overrightarrow{OB}$가 이루는 도형.

| 종류 | 범위 | 예시 |
|------|------|------|
| 예각 (acute) | $0° < \theta < 90°$ | $45°$, $60°$ |
| 직각 (right) | $\theta = 90°$ | $90°$ (정확히) |
| 둔각 (obtuse) | $90° < \theta < 180°$ | $120°$, $135°$ |
| 평각 (straight) | $\theta = 180°$ | 일직선 |
| 우각 (reflex) | $180° < \theta < 360°$ | $270°$ |

**여각**: 합이 90°인 두 각. **보각**: 합이 180°인 두 각.

### 맞꼭지각, 동위각, 엇각

**두 직선이 한 점에서 만날 때**:

두 직선이 교차하면 4개의 각이 생긴다. 서로 마주 보는 각을 **맞꼭지각(vertical angles)**이라 하며, 항상 크기가 같다.

**왜 맞꼭지각이 같은가?** 직선 위의 인접각의 합은 180°이므로:
- $\angle a + \angle b = 180°$
- $\angle b + \angle c = 180°$
- 따라서 $\angle a = \angle c$ ✓

**두 평행선이 제3의 직선과 만날 때**:

$$\ell \parallel m \iff \text{동위각이 같고 엇각이 같다}$$

| 관계 | 설명 | 크기 |
|------|------|------|
| 동위각(corresponding) | 같은 위치(같은 쪽, 같은 방향) | 서로 같다 |
| 엇각(alternate interior) | 두 평행선 사이에서 엇갈린 위치 | 서로 같다 |
| 동측내각(co-interior) | 같은 쪽 내부 | 합이 $180°$ |

## 위치 관계

### 평면 위 두 직선의 위치

| 관계 | 교점 수 | 예시 |
|------|--------|------|
| 평행 ($\ell \parallel m$) | 0 | 철로의 두 레일 |
| 한 점에서 만남 | 1 | 일반적인 두 직선 |
| 일치 | 무한히 많음 | 같은 직선 |

### 공간에서 두 직선의 위치

평면에서는 두 직선이 만나거나 평행이거나 일치하는 세 가지이지만, 공간에서는 **꼬인 위치**라는 새로운 경우가 존재한다.

| 관계 | 공통점 | 같은 평면? |
|------|--------|---------|
| 한 점에서 만남 | 1개 | ○ |
| 평행 | 없음 | ○ |
| 일치 | 무한히 많음 | ○ |
| **꼬인 위치(skew)** | 없음 | ✗ |

**꼬인 위치**: 만나지도 않고 평행하지도 않은 공간 속 두 직선. 직육면체를 상상할 때, 위 면의 한 모서리와 아래 면의 인접하지 않은 모서리가 꼬인 위치에 있다.

**예**: 고속도로 교차로에서 수평으로 지나가는 도로와 다리 위로 지나가는 도로는 꼬인 위치 관계다. 서로 만나지 않고(다리 높이 차이), 평행하지도 않다(다른 방향).

## 작도와 합동

### 작도란 무엇인가?

**작도(construction)**는 눈금 없는 자와 컴퍼스만으로 도형을 그리는 것이다.

- **눈금 없는 자**: 두 점을 잇는 직선을 그릴 수 있지만, 길이를 측정하거나 옮길 수 없다.
- **컴퍼스**: 원을 그리거나 두 점 사이의 거리(길이)를 옮길 수 있다.

왜 자의 눈금을 사용하면 안 될까? 눈금이 있으면 임의의 길이를 정확히 만들 수 있어 문제가 너무 단순해진다. 작도는 "가장 원시적인 도구만으로 무엇을 만들 수 있는가"를 탐구하는 것이다.

작도 불가능 문제들이 있다. "원과 같은 넓이의 정사각형 작도(원의 정사각화)", "임의의 각의 삼등분" 등은 작도 불가능함이 19세기에 증명되었다.

### 기본 작도

1. **선분의 수직이등분선**: 두 끝점에서 같은 반지름으로 호를 그려 교점 두 개를 잇는다.
2. **각의 이등분선**: 꼭짓점에서 호를 그려 두 변 위 점을 구한 후, 그 두 점에서 같은 반지름으로 호를 그려 교점을 잇는다.

### 삼각형의 합동

두 도형이 **합동(congruent)**이면 모양과 크기가 완전히 같아 겹칠 수 있다.

**왜 삼각형은 세 요소만 알면 합동을 결정할 수 있는가?**

삼각형에는 3개의 각과 3개의 변, 총 6개의 요소가 있다. 그런데 삼각형의 내각의 합이 180°이므로 각이 두 개 정해지면 나머지 하나가 자동으로 결정된다. 이런 제약 때문에 6개 중 3개만 적절히 알아도 나머지가 결정된다.

| 기호 | 합동 조건 | 설명 |
|------|---------|------|
| **SSS** | 세 쌍의 대응변이 같다 | 가장 기본 |
| **SAS** | 두 쌍의 대응변과 그 끼인각이 같다 | "끼인각"에 주의 |
| **ASA** | 한 쌍의 대응변과 그 양 끝각이 같다 | "양 끝각"에 주의 |

**합동이 아닌 조건들:**
- **SSA**: 두 변과 끼인각이 아닌 대각이 주어지면 두 가지 다른 삼각형이 가능하다.
- **AAA**: 세 각이 같으면 닮음이지만 합동은 아니다. (크기가 다를 수 있다)

**흔한 실수**: SAS에서 "끼인각"은 두 변 사이에 있는 각이어야 한다. 두 변이 정해지고 그 대각이 주어지면 합동 조건이 안 된다.

## 삼각형의 성질

### 삼각형의 내각의 합

삼각형의 내각의 합은 항상 **180°**이다.

**증명 아이디어**: $A$를 지나며 $BC$에 평행한 직선을 그으면, 엇각에 의해 두 각이 삼각형의 내각과 같다. 세 각이 모여 평각(180°)을 이룬다.

**외각**: 한 내각의 이웃한 외부각. 이 외각의 크기는 **나머지 두 내각의 합**이다.

$$\text{외각} = \angle A + \angle B \quad (\angle C\text{의 외각일 때})$$

**활용 예제**: 삼각형 ABC에서 $\angle A = 50°$, 외각이 $120°$이면 $\angle B$는?
$\angle B = 120° - 50° = 70°$, $\angle C = 180° - 50° - 70° = 60°$

### 이등변삼각형

두 변의 길이가 같은 삼각형 ($AB = AC$).

**성질**: **밑각이 같다** ($\angle B = \angle C$)

**역**: $\angle B = \angle C$이면 $AB = AC$ (이등변삼각형)

**대칭성**: 이등변삼각형의 꼭짓점 $A$에서 밑변 $BC$에 내린 수선의 발은 $BC$의 중점이다. 즉, 이 수선이 꼭짓점 각의 이등분선이기도 하고, 밑변의 수직이등분선이기도 하다.

### 직각삼각형의 합동 조건

직각삼각형에는 특별한 합동 조건이 있다.

| 기호 | 조건 |
|------|------|
| **RHS** | 빗변과 한 예각이 같다 (Hypotenuse-Angle) |
| **RHL** | 빗변과 다른 한 변이 같다 (Hypotenuse-Leg) |

직각이 이미 공통이므로 일반 삼각형의 SAS/ASA보다 조건이 느슨하다.

### 피타고라스 정리

직각삼각형에서 직각을 낀 두 변의 길이 $a$, $b$, 빗변 $c$에 대해:

$$a^2 + b^2 = c^2$$

**왜 성립하는가? (넓이 이용 증명)**

변의 길이가 $a+b$인 큰 정사각형 안에 합동인 직각삼각형 4개를 넣는다.

$$\text{큰 정사각형 넓이} = (a+b)^2 = a^2 + 2ab + b^2$$

$$\text{4개의 삼각형 넓이} = 4 \times \frac{ab}{2} = 2ab$$

$$\text{가운데 정사각형 넓이} = (a+b)^2 - 2ab = a^2 + b^2$$

가운데 정사각형의 한 변이 $c$이므로 넓이 $= c^2$.

$$\therefore\quad a^2 + b^2 = c^2 \quad \checkmark$$

**역**: $a^2 + b^2 = c^2$이면 직각삼각형 (각 $C = 90°$)이다.

**피타고라스 수**: 세 정수가 $a^2 + b^2 = c^2$를 만족하는 경우

| $(a, b, c)$ | 확인 |
|------------|------|
| $(3, 4, 5)$ | $9 + 16 = 25$ ✓ |
| $(5, 12, 13)$ | $25 + 144 = 169$ ✓ |
| $(8, 15, 17)$ | $64 + 225 = 289$ ✓ |
| $(7, 24, 25)$ | $49 + 576 = 625$ ✓ |

이들의 정수배도 성립: $(6, 8, 10)$, $(9, 12, 15)$ 등.

**실생활 응용:**

건축에서 직각 확인: 줄자 세 개로 3-4-5 비율을 만들면 직각 확인 가능 (옛날 목수들의 방법).

좌표에서의 거리: $(x_1, y_1)$과 $(x_2, y_2)$ 사이 거리 $= \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$는 피타고라스 정리의 직접 응용.

## 다각형

### 다각형의 내각의 합

$n$각형을 한 꼭짓점에서 그은 대각선으로 삼각형으로 분할하면 $(n-2)$개의 삼각형이 생긴다.

$$n\text{각형의 내각의 합} = 180° \times (n-2)$$

| 도형 | $n$ | 내각의 합 |
|------|-----|---------|
| 삼각형 | 3 | $180°$ |
| 사각형 | 4 | $360°$ |
| 오각형 | 5 | $540°$ |
| 육각형 | 6 | $720°$ |
| 팔각형 | 8 | $1080°$ |
| 십각형 | 10 | $1440°$ |

**외각의 합**: 모든 볼록 다각형에서 외각의 합은 **360°**. 이것은 $n$에 무관한 놀라운 결과다.

직관: 한 점에서 출발해 다각형을 한 바퀴 돌면서 각 꼭짓점에서 방향을 꺾으면, 한 바퀴(360°)를 돌아 원점으로 돌아온다.

**정$n$각형 한 내각**: $\dfrac{180°(n-2)}{n}$

벌집 구조가 정육각형인 이유: 평면을 틈 없이 채울 수 있는 정다각형은 정삼각형($60°$), 정사각형($90°$), 정육각형($120°$) 세 가지뿐. (내각이 $360° \div k$, 즉 $360°$의 약수여야 함)

### 대각선의 수

$n$각형의 한 꼭짓점에서 그을 수 있는 대각선: $(n-3)$개 (자기 자신과 인접 두 꼭짓점 제외)

$n$개의 꼭짓점 각각에서 $(n-3)$개씩 → $n(n-3)$개이지만 각 대각선이 두 번씩 계산되므로:

$$\text{대각선의 수} = \frac{n(n-3)}{2}$$

## 원의 성질

### 기본 용어와 공식

| 용어 | 설명 |
|------|------|
| 중심 $O$, 반지름 $r$ | |
| 현 $\overline{AB}$ | 원 위의 두 점을 잇는 선분 |
| 호 $\stackrel{\frown}{AB}$ | 원 위의 두 점 사이의 곡선 부분 |
| 현의 수직이등분선 | 항상 원의 중심을 지난다 |
| 접선 | 원과 한 점에서만 만나는 직선 |

$$\text{원의 둘레} = 2\pi r, \qquad \text{원의 넓이} = \pi r^2$$

원주율 $\pi \approx 3.14159\ldots$는 무리수다 — 절대 끝나지도 않고 반복되지도 않는 소수점.

### 원과 직선의 관계

원의 중심에서 직선까지의 거리를 $d$, 반지름을 $r$라 하면:

| 조건 | 관계 | 교점 수 |
|------|------|--------|
| $d < r$ | 직선이 원과 두 점에서 만난다 (할선) | 2 |
| $d = r$ | 직선이 원과 한 점에서 만난다 (접선) | 1 |
| $d > r$ | 직선이 원과 만나지 않는다 | 0 |

**접선의 성질**: 접선은 접점에서 반지름에 **수직**이다. 이것을 이용해 원 밖의 점에서 접선을 작도할 수 있다.

### 현의 수직이등분선 정리

원에서 현의 수직이등분선은 원의 중심을 지난다. 역도 성립.

이를 이용해 3점이 주어지면 이 세 점을 지나는 원의 중심을 작도할 수 있다 (두 현의 수직이등분선의 교점).

### 원주각 정리

**원주각**: 원 위의 한 점에서 같은 호에 대해 이루는 각.

**중심각과 원주각의 관계**:

$$\text{원주각} = \frac{1}{2} \times \text{중심각}$$

**같은 호에 대한 원주각은 모두 같다.**

이 정리가 왜 중요한가? 건축에서 "두 건물 사이의 각도가 일정한 위치의 집합은 원호"라는 사실로 이어진다.

**특별한 경우**: 반원(지름에 대한 원주각)은 항상 90°.

$$\text{지름에 대한 원주각} = \frac{1}{2} \times 180° = 90°$$

## 입체도형

### 오일러 공식

볼록 다면체에서 꼭짓점($V$), 모서리($E$), 면($F$)의 수는 다음 관계를 만족한다:

$$V - E + F = 2$$

이 공식은 도형의 위상적 성질을 나타낸다. 구체적인 크기나 모양에 무관하다.

| 다면체 | 꼭짓점 $V$ | 모서리 $E$ | 면 $F$ | $V - E + F$ |
|--------|----------|----------|-------|------------|
| 사면체 | 4 | 6 | 4 | 2 |
| 정육면체 | 8 | 12 | 6 | 2 |
| 팔면체 | 6 | 12 | 8 | 2 |
| 축구공(아이코사헤드론) | 12 | 30 | 20 | 2 |

이 공식은 위상수학과 [이산수학 그래프이론](/math/discrete/graph-theory)의 출발점이다.

### 각기둥과 각뿔

**각기둥** (밑면이 $n$각형):

$$\text{부피} = \text{밑넓이} \times \text{높이}$$
$$\text{겉넓이} = 2 \times \text{밑넓이} + \text{옆넓이} = 2S + l \times h$$

(밑면 둘레 $l$, 높이 $h$)

**직육면체** (가로 $a$, 세로 $b$, 높이 $c$):

$$\text{부피} = abc, \qquad \text{겉넓이} = 2(ab + bc + ca)$$

**각뿔** (밑면 어떤 $n$각형이든):

$$\text{부피} = \frac{1}{3} \times \text{밑넓이} \times \text{높이}$$

각뿔의 부피가 같은 밑면·높이 각기둥의 $\dfrac{1}{3}$인 이유: 같은 밑면과 높이를 가진 삼각기둥을 3개의 합동인 삼각뿔로 나눌 수 있다.

### 회전체

**원기둥** (반지름 $r$, 높이 $h$):

$$\text{겉넓이} = 2\pi r^2 + 2\pi rh = 2\pi r(r + h), \qquad \text{부피} = \pi r^2 h$$

**원뿔** (반지름 $r$, 높이 $h$):

모선의 길이 $l = \sqrt{r^2 + h^2}$ (피타고라스 정리)

$$\text{겉넓이} = \pi r^2 + \pi r l = \pi r(r + l), \qquad \text{부피} = \frac{1}{3}\pi r^2 h$$

**구** (반지름 $r$):

$$\text{겉넓이} = 4\pi r^2, \qquad \text{부피} = \frac{4}{3}\pi r^3$$

구의 겉넓이 $4\pi r^2$: 같은 반지름의 대원(great circle) 넓이 $\pi r^2$의 4배다. 아르키메데스가 이를 발견하고 매우 자랑스러워해, 무덤에 구와 외접 원기둥 그림을 새겨달라고 했다는 이야기가 있다.

구의 겉넓이와 부피 공식은 [대학 미적분학](/math/university/calculus)의 회전체 적분으로 엄밀히 유도된다.

## 닮음

### 닮음의 정의

두 도형이 **닮음(similar, $\sim$)**이면, 한 도형을 적절히 확대/축소하면 다른 도형과 겹친다.

닮음의 조건:
- 대응하는 각의 크기가 모두 같고
- 대응하는 변의 길이의 비가 일정하다 (닮음비)

합동 $\cong$은 닮음비 $1:1$인 특수한 닮음이다.

### 삼각형의 닮음 조건

| 기호 | 조건 |
|------|------|
| **AA** | 두 쌍의 각이 각각 같다 (세 번째 각은 자동) |
| **SAS 닮음** | 두 쌍의 변의 비가 같고 그 끼인각이 같다 |
| **SSS 닮음** | 세 쌍의 변의 비가 모두 같다 |

### 닮음비와 넓이비·부피비

닮음비가 $m : n$이면:

$$\text{넓이비} = m^2 : n^2, \qquad \text{부피비} = m^3 : n^3$$

**왜 제곱, 세제곱인가?**

넓이는 2차원 — 가로와 세로 모두 $m : n$으로 확대되므로 넓이는 $m^2 : n^2$.
부피는 3차원 — 가로·세로·높이 모두 확대되므로 부피는 $m^3 : n^3$.

**실용적 예**: 지도의 축척. 축척 $1 : 50000$ 지도에서 $2\,\text{cm}$가 실제로는 $1\,\text{km}$이다. 지도 위 $1\,\text{cm}^2$는 실제 $50000^2 = 25\,\text{억 cm}^2 = 0.25\,\text{km}^2$에 해당.

**생물학에서의 닮음비**: 동물이 커질수록 겉넓이(호흡, 열 방출)에 비해 부피(근육, 내장)가 더 빠르게 커진다. 그래서 코끼리는 쥐보다 체온 유지와 산소 공급이 더 어렵다. (넓이 $\propto l^2$, 부피 $\propto l^3$)

## 연습문제

**문제 1.** 삼각형 ABC에서 $\angle A = 70°$, $\angle B = 55°$일 때, $\angle C$와 꼭짓점 C에서의 외각을 구하여라.

> **풀이**
>
> $\angle C = 180° - 70° - 55° = 55°$
>
> 외각 $= 180° - \angle C = 180° - 55° = 125°$
>
> 또는: 외각 $= \angle A + \angle B = 70° + 55° = 125°$ ✓
>
> 참고: $\angle B = \angle C = 55°$이므로 $\triangle ABC$는 이등변삼각형 ($CA = AB$).

---

**문제 2.** 정팔각형의 한 내각과 한 외각을 구하여라.

> **풀이**
>
> 내각의 합 $= 180° \times (8-2) = 180° \times 6 = 1080°$
>
> 한 내각 $= \dfrac{1080°}{8} = 135°$
>
> 한 외각 $= 180° - 135° = 45°$ (또는 $\dfrac{360°}{8} = 45°$)

---

**문제 3.** 직각삼각형에서 두 예각의 합은 90°임을 설명하고, 빗변이 13이고 한 예각의 삼각비로 다른 변의 길이를 구하여라. (한 예각 = 30°)

> **풀이**
>
> 직각삼각형에서 직각 $= 90°$이므로 나머지 두 각의 합 $= 180° - 90° = 90°$.
>
> 빗변 $c = 13$, 한 각이 $30°$이면:
> - $a = c\sin 30° = 13 \times \dfrac{1}{2} = 6.5$
> - $b = c\cos 30° = 13 \times \dfrac{\sqrt{3}}{2} = \dfrac{13\sqrt{3}}{2}$
>
> 검증 (피타고라스): $a^2 + b^2 = 6.5^2 + \left(\dfrac{13\sqrt{3}}{2}\right)^2 = 42.25 + 126.75 = 169 = 13^2$ ✓

---

**문제 4.** 반지름이 9이고 중심각이 $80°$인 부채꼴의 호의 길이와 넓이를 구하여라.

> **풀이**
>
> 호의 길이 $= 2\pi r \times \dfrac{80}{360} = 2\pi \times 9 \times \dfrac{2}{9} = 4\pi$
>
> 넓이 $= \pi r^2 \times \dfrac{80}{360} = \pi \times 81 \times \dfrac{2}{9} = 18\pi$
>
> 또는: 넓이 $= \dfrac{1}{2} r \times (\text{호의 길이}) = \dfrac{1}{2} \times 9 \times 4\pi = 18\pi$ ✓

---

**문제 5.** 밑면의 반지름이 4이고 높이가 3인 원뿔의 겉넓이와 부피를 구하여라.

> **풀이**
>
> 모선 $l = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5$
>
> 겉넓이 $= \pi \times 4^2 + \pi \times 4 \times 5 = 16\pi + 20\pi = 36\pi$
>
> 부피 $= \dfrac{1}{3} \times \pi \times 4^2 \times 3 = \dfrac{1}{3} \times 48\pi = 16\pi$

---

**문제 6.** 두 삼각형 ABC와 DEF에서 $\dfrac{AB}{DE} = \dfrac{BC}{EF} = \dfrac{CA}{FD} = \dfrac{3}{2}$이다.
(a) 두 삼각형의 닮음 조건을 말하여라.
(b) $\triangle ABC$의 넓이가 $45\,\text{cm}^2$이면 $\triangle DEF$의 넓이는?

> **풀이**
>
> (a) 세 쌍의 대응변 비가 모두 $3:2$로 같다 → **SSS 닮음**
>
> (b) 닮음비 $3:2$ → 넓이비 $9:4$
>
> $\triangle DEF$의 넓이 $= 45 \times \dfrac{4}{9} = 20\,\text{cm}^2$
