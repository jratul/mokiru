## 왜 라플라스 변환이 필요한가

[상미분방정식](/math/university/ode)을 풀 때 가장 번거로운 부분은 미분·적분이라는 연산 자체다. 만약 이 연산을 곱셈이나 나눗셈 같은 훨씬 단순한 대수 연산으로 바꿀 수 있다면 어떨까? 라플라스 변환은 정확히 이 일을 해낸다 — 시간 영역의 미분방정식을 "$s$-영역"이라는 다른 세계로 옮기면, 미분은 단순한 곱셈이 되고 복잡한 ODE는 대수 방정식으로 변한다. 이를 풀고 나서 다시 원래 세계로 돌아오면(역변환) 답을 얻는다.

이 아이디어는 로그가 곱셈을 덧셈으로 바꿔 계산을 쉽게 만들었던 것과 본질적으로 같은 전략이다 — "어려운 연산의 세계"에서 "쉬운 연산의 세계"로 문제를 옮긴 뒤, 쉬운 세계에서 풀고, 다시 원래 세계로 답을 되돌리는 것. [공학수학 푸리에 해석](/math/engineering-math/fourier)의 미분 성질($\mathcal{F}\{f'\} = i\omega\hat{f}$)과 본질적으로 같은 원리이지만, 라플라스 변환은 초기 조건을 자연스럽게 방정식 안에 포함시킨다는 점에서 공학의 초기값 문제(시스템이 특정 상태에서 출발해 어떻게 진화하는가)에 특히 잘 맞는다. 신호처리, 제어시스템 설계, 전기회로 해석의 표준 도구다.

## 라플라스 변환의 정의

$t \geq 0$에서 정의된 함수 $f(t)$의 **라플라스 변환**은 다음의 적분으로 정의된다:

$$
\mathcal{L}\{f(t)\} = F(s) = \int_0^{\infty} e^{-st} f(t)\,dt
$$

여기서 $s$는 복소수 변수다. $e^{-st}$라는 "감쇠 인자"를 곱해서 적분하는 이유는, $f(t)$ 자체는 시간이 지나도 커지거나 진동을 계속할 수 있지만, $s$의 실수부를 충분히 크게 잡으면 $e^{-st}$가 그보다 빠르게 0으로 줄어들어 적분이 유한한 값으로 수렴하도록 만들 수 있기 때문이다.

**수렴 조건**: 어떤 상수 $M, a$가 존재해서 $|f(t)| \leq Me^{at}$(즉 $f$가 지수함수보다 빠르게 커지지 않음)를 만족하면, $\text{Re}(s) > a$인 모든 $s$에서 적분이 수렴한다.

**선형성**: 라플라스 변환은 미분·적분과 마찬가지로 선형 연산이다:

$$
\mathcal{L}\{af(t) + bg(t)\} = aF(s) + bG(s)
$$

이 성질 덕분에 복잡한 함수를 이미 알고 있는 간단한 함수들의 조합으로 쪼갠 뒤, 각각을 변환해서 더하기만 하면 된다.

## 기본 변환 표

아래 표는 자주 등장하는 함수들의 변환을 미리 계산해둔 것이다. 실전에서는 매번 적분을 직접 계산하는 대신, 주어진 함수를 이 표의 형태로 짜맞추는 방식으로 작업한다(뒤의 성질들이 이 짜맞추기를 돕는다).

| $f(t)$ | $F(s) = \mathcal{L}\{f(t)\}$ | 조건 |
|--------|------------------------------|------|
| $1$ (단위함수) | $\dfrac{1}{s}$ | $s > 0$ |
| $t^n$ | $\dfrac{n!}{s^{n+1}}$ | $s > 0$ |
| $e^{at}$ | $\dfrac{1}{s-a}$ | $s > a$ |
| $t e^{at}$ | $\dfrac{1}{(s-a)^2}$ | |
| $\sin \omega t$ | $\dfrac{\omega}{s^2 + \omega^2}$ | |
| $\cos \omega t$ | $\dfrac{s}{s^2 + \omega^2}$ | |
| $e^{at}\sin\omega t$ | $\dfrac{\omega}{(s-a)^2+\omega^2}$ | |
| $e^{at}\cos\omega t$ | $\dfrac{s-a}{(s-a)^2+\omega^2}$ | |
| $\delta(t)$ (임펄스) | $1$ | |
| $u(t-a)$ (단위계단) | $\dfrac{e^{-as}}{s}$ | |
| $t^n e^{at}$ | $\dfrac{n!}{(s-a)^{n+1}}$ | |

$\mathcal{L}\{1\} = 1/s$부터 직접 확인해보자: $\int_0^\infty e^{-st}\,dt = \left[-\dfrac{e^{-st}}{s}\right]_0^\infty = 0 - \left(-\dfrac{1}{s}\right) = \dfrac{1}{s}$ (단, $s>0$이라 $t\to\infty$일 때 $e^{-st}\to0$). 나머지 항목들도 같은 방식으로 직접 적분해서 유도할 수 있다.

## 주요 성질

### 도함수의 변환 — 라플라스 변환의 핵심 능력

$$
\mathcal{L}\{f'(t)\} = sF(s) - f(0)
$$

이 공식은 부분적분으로 유도된다: $\int_0^\infty e^{-st}f'(t)\,dt = \left[e^{-st}f(t)\right]_0^\infty + s\int_0^\infty e^{-st}f(t)\,dt = -f(0) + sF(s)$.

여기서 놀라운 점은, "미분"이라는 연산이 변환 후에는 $s$를 곱하는 대수 연산으로 바뀌면서, **초기값 $f(0)$이 자동으로 방정식 안에 끼어든다**는 것이다. 고계 도함수도 같은 방식으로 확장된다:

$$
\mathcal{L}\{f''(t)\} = s^2F(s) - sf(0) - f'(0)
$$

$$
\mathcal{L}\{f^{(n)}(t)\} = s^nF(s) - s^{n-1}f(0) - s^{n-2}f'(0) - \cdots - f^{(n-1)}(0)
$$

**왜 이것이 결정적으로 유용한가**: ODE를 일반해(임의 상수 포함) + 특수해로 풀고 나서 초기 조건을 나중에 대입하는 전통적인 방법과 달리, 라플라스 변환은 **처음부터 초기값이 대수 방정식에 포함된 채로** 문제를 풀어준다. 그래서 별도의 "상수 결정" 단계 없이 한 번에 초기값 문제(IVP)의 해가 나온다.

### 주파수 이동 (s-shifting)

$$
\mathcal{L}\{e^{at}f(t)\} = F(s-a)
$$

시간 영역에서 지수함수 $e^{at}$를 곱하는 것은, $s$-영역에서는 그저 변수를 $s \to s-a$로 평행이동시키는 것과 같다.

**예**: $\mathcal{L}\{t\} = 1/s^2$임을 알고 있으면, $\mathcal{L}\{te^{2t}\}$는 $s \to s-2$로 치환만 하면 $\dfrac{1}{(s-2)^2}$이다 — 새로 적분을 계산할 필요가 없다.

### 시간 이동 (t-shifting)

$$
\mathcal{L}\{f(t-a)u(t-a)\} = e^{-as}F(s) \quad (a > 0)
$$

신호를 시간축에서 $a$만큼 뒤로 미루면($u(t-a)$가 $t<a$에서 신호를 0으로 만듦), 변환된 함수에는 $e^{-as}$라는 위상 지연 인자가 곱해진다. 스위치를 특정 시각에 켜는 회로, 지연 시스템 등을 다룰 때 쓰인다.

### 합성곱 정리

$$
\mathcal{L}\{(f * g)(t)\} = F(s) \cdot G(s), \qquad (f * g)(t) = \int_0^t f(\tau)g(t-\tau)\,d\tau
$$

시간 영역의(계산이 번거로운) 합성곱이 $s$-영역에서는 단순한 곱셈이 된다 — 이는 [푸리에 변환](/math/engineering-math/fourier)의 합성곱 정리와 정확히 같은 구조로, 뒤에서 다룰 전달함수의 "직렬 연결" 개념의 수학적 근거가 된다.

## 역 라플라스 변환

$s$-영역에서 문제를 풀고 나면, 다시 시간 영역의 답 $f(t)$로 돌아와야 한다. 가장 표준적인 방법은 **부분분수 분해**로 복잡한 $F(s)$를 변환 표에 있는 간단한 조각들의 합으로 쪼갠 뒤, 각 조각을 표에서 거꾸로 찾는 것이다.

**예제.** $F(s) = \dfrac{3s+7}{(s+1)(s+2)}$의 역변환을 구하자.

> 부분분수로 분해한다고 가정하면:
>
> $$F(s) = \frac{A}{s+1} + \frac{B}{s+2}$$
>
> $A$를 구하기 위해 양변에 $(s+1)$을 곱한 뒤 $s=-1$을 대입한다(이렇게 하면 $B$가 곱해진 항이 0이 되어 사라진다):
>
> $$A = \frac{3(-1)+7}{(-1)+2} = \frac{4}{1} = 4$$
>
> 같은 방식으로 $s=-2$를 대입해 $B$를 구한다:
>
> $$B = \frac{3(-2)+7}{(-2)+1} = \frac{1}{-1} = -1$$
>
> 변환 표에서 $\mathcal{L}\{e^{at}\} = \dfrac{1}{s-a}$를 거꾸로 적용하면:
>
> $$f(t) = \mathcal{L}^{-1}\!\left\{\frac{4}{s+1} - \frac{1}{s+2}\right\} = 4e^{-t} - e^{-2t}$$

**분모가 복소근을 가질 때**: 분모가 $s^2 + as + b$처럼 실근으로 인수분해되지 않는 형태라면, 완전제곱으로 변형해 $\sin$·$\cos$의 표준 형태로 짜맞춘다.

$$
\frac{1}{s^2 + 2s + 5} = \frac{1}{(s+1)^2 + 4} \implies \mathcal{L}^{-1} = \frac{1}{2}e^{-t}\sin 2t
$$

이때 분모를 $(s+1)^2 + 2^2$로 보고 표의 $\mathcal{L}\{e^{at}\sin\omega t\} = \dfrac{\omega}{(s-a)^2+\omega^2}$($a=-1, \omega=2$) 형태와 대조하되, 분자에 $\omega=2$가 없으므로 $\dfrac{1}{2}$을 곱해 보정한다는 점에 유의한다.

## ODE에 적용

라플라스 변환으로 ODE를 푸는 절차는 항상 동일한 세 단계를 거친다: **① 양변을 라플라스 변환** → **② $s$-영역에서 $Y(s)$에 대해 대수적으로 풀기** → **③ 역변환으로 $y(t)$ 복원**.

**예제.** $y'' + 3y' + 2y = 0$, $y(0) = 1$, $y'(0) = 0$을 풀자.

> **1단계 — 변환**: 도함수의 변환 공식을 각 항에 적용한다. $\mathcal{L}\{y''\} = s^2Y - sy(0) - y'(0) = s^2Y - s$, $\mathcal{L}\{y'\} = sY - y(0) = sY - 1$.
>
> $$(s^2 Y - s) + 3(sY - 1) + 2Y = 0$$
>
> **2단계 — 대수적으로 정리**: $Y$에 대해 묶으면:
>
> $$Y(s^2 + 3s + 2) + (-s - 3) = 0 \implies Y = \frac{s+3}{(s+1)(s+2)}$$
>
> 부분분수로 분해하면 $Y = \dfrac{2}{s+1} - \dfrac{1}{s+2}$ (앞선 예제와 같은 방식으로 $A, B$를 구할 수 있다).
>
> **3단계 — 역변환**:
>
> $$y(t) = 2e^{-t} - e^{-2t}$$
>
> 검산: $y(0) = 2-1=1$ ✓. $y'(t) = -2e^{-t}+2e^{-2t}$이므로 $y'(0) = -2+2=0$ ✓. 두 초기 조건 모두 정확히 만족한다.

## 전달함수와 제어이론

### 전달함수 (Transfer Function)

선형 시불변(LTI, Linear Time-Invariant) 시스템 — 입력과 출력의 관계가 시간에 따라 변하지 않고 선형적인 시스템 — 에서, 모든 초기 조건이 0일 때 입력의 변환 $X(s)$와 출력의 변환 $Y(s)$의 비율을 **전달함수**라 한다:

$$
H(s) = \frac{Y(s)}{X(s)}
$$

전달함수는 시스템 자체의 "성질"만을 담고 있으며 특정 입력에 의존하지 않는다 — 어떤 입력을 넣어도 $Y(s) = H(s)X(s)$라는 관계로 출력을 즉시 예측할 수 있다.

**예**: $y'' + 3y' + 2y = x(t)$ (초기 조건 0)를 라플라스 변환하면 $(s^2+3s+2)Y = X$이므로 전달함수는:

$$
H(s) = \frac{1}{s^2 + 3s + 2}
$$

### 극점과 안정성

전달함수 $H(s)$의 분모가 0이 되는 $s$ 값을 **극점(pole)**이라 한다. 극점의 위치는 시스템이 시간이 지남에 따라 어떻게 행동하는지를 결정한다 — 역변환하면 극점 $s = p$마다 $e^{pt}$ 형태의 항이 나오는데, $p$의 실수부가 음수면 이 항은 시간이 지날수록 0으로 감쇠하고, 양수면 무한히 커진다.

| 극점 위치 | 시스템 응답 |
|---------|-----------|
| 좌반평면 ($\text{Re}(s) < 0$) | 안정 (시간이 지나면 응답이 0으로 감쇠) |
| 허수축 ($\text{Re}(s) = 0$) | 한계 안정 (진폭이 줄지도 늘지도 않고 유지) |
| 우반평면 ($\text{Re}(s) > 0$) | 불안정 (응답이 시간에 따라 발산) |

이것이 제어이론에서 극점 위치를 그토록 중요하게 다루는 이유다 — 시스템을 설계할 때, 모든 극점을 좌반평면에 위치시키는 것이 "안정적인 시스템"을 만드는 핵심 목표가 된다.

**임펄스 응답**: $h(t) = \mathcal{L}^{-1}\{H(s)\}$는 시스템에 순간적인 충격($\delta(t)$)을 가했을 때의 반응으로, 시스템의 모든 특성을 완전히 담고 있다 — 임펄스 응답을 알면 합성곱 정리를 통해 임의의 입력에 대한 출력을 계산할 수 있다.

**블록 다이어그램 규칙**: 두 시스템을 **직렬**로 연결하면 전달함수는 곱해진다($H_1 H_2$, 신호가 첫 시스템을 통과한 결과가 두 번째 시스템의 입력이 되므로). **병렬**로 연결하면 전달함수는 더해진다($H_1 + H_2$). **피드백**(출력의 일부를 입력으로 되돌리는 구조)에서는 $\dfrac{H}{1 + HG}$의 형태가 되는데, 이 피드백 구조가 바로 에어컨의 온도 조절, 자율주행차의 속도 제어 등 현대 제어시스템의 근간이다.

## 흔한 실수와 주의할 점

**실수 1: 초기 조건을 변환 이후에 대입하려 하기**

라플라스 변환의 장점은 초기 조건이 변환 **과정에서** 자동으로 방정식에 들어간다는 것이다. $\mathcal{L}\{y'\} = sY - y(0)$처럼, 변환 단계에서 바로 $y(0)$, $y'(0)$ 등을 대입해야 한다.

**실수 2: 부분분수 분해에서 분모의 인수분해를 건너뛰기**

부분분수를 세우기 전에 분모를 완전히 인수분해(또는 완전제곱 형태로 정리)해야 한다. 실근인지 복소근(공액 복소근)인지에 따라 부분분수의 형태(선형 vs. 완전제곱+상수)가 달라진다.

**실수 3: 극점의 실수부만 보고 안정성을 판단하지 않기**

시스템의 안정성은 극점의 **실수부** 부호로만 결정된다. 허수부는 진동의 주파수를 결정할 뿐 안정성과는 무관하다 — $s = -1+3i$는 실수부가 음수이므로 (진동하며) 안정하다.

**실수 4: 라플라스 변환과 푸리에 변환을 혼동하기**

라플라스 변환은 $t \geq 0$에서 정의되고 $e^{-st}$의 감쇠 덕분에 발산하는 함수도 다룰 수 있지만, [푸리에 변환](/math/engineering-math/fourier)은 전체 실수축에서 정의되고 절대 적분 가능한 함수에만 (기본적으로) 적용된다. 둘은 $s = i\omega$로 놓으면 밀접하게 연결되지만 정확히 같은 도구는 아니다.

## 연습문제

**문제 1.** $\mathcal{L}\{te^{2t}\}$를 구하여라.

> **풀이**
>
> 기본 변환 $\mathcal{L}\{t\} = \dfrac{1}{s^2}$에서 시작한다. $e^{2t}$를 곱하는 것은 주파수 이동 성질($s \to s-2$)에 대응되므로:
>
> $$\mathcal{L}\{te^{2t}\} = \frac{1}{(s-2)^2}$$

---

**문제 2.** $y' + 2y = 4$, $y(0) = 1$을 라플라스 변환으로 풀어라.

> **풀이**
>
> 양변을 변환한다: $\mathcal{L}\{y'\} = sY - y(0) = sY - 1$이고, 우변의 상수 $4$는 $\mathcal{L}\{4\} = 4/s$.
>
> $$(sY - 1) + 2Y = \frac{4}{s}$$
>
> $Y$에 대해 정리하면 $Y(s+2) = \dfrac{4}{s} + 1 = \dfrac{4+s}{s}$이므로:
>
> $$Y = \frac{s+4}{s(s+2)}$$
>
> 부분분수 분해: $Y = \dfrac{A}{s} + \dfrac{B}{s+2}$. $s=0$ 대입: $A = \dfrac{4}{2}=2$. $s=-2$ 대입: $B = \dfrac{-2+4}{-2} = -1$.
>
> $$Y = \frac{2}{s} - \frac{1}{s+2} \implies y(t) = 2 - e^{-2t}$$
>
> 검산: $y(0) = 2-1=1$ ✓.

---

**문제 3.** $\mathcal{L}^{-1}\!\left\{\dfrac{s+1}{s^2+2s+5}\right\}$를 구하여라.

> **풀이**
>
> 먼저 분모를 완전제곱 형태로 바꾼다: $s^2+2s+5 = (s+1)^2+4$.
>
> 분자도 $(s+1)^2+4$의 "$s-a$" 형태에 맞춰보면, 분자가 정확히 $s+1 = s-(-1)$이므로 $a=-1$인 표의 항목 $\mathcal{L}\{e^{at}\cos\omega t\} = \dfrac{s-a}{(s-a)^2+\omega^2}$과 정확히 일치한다($\omega=2$).
>
> $$\mathcal{L}^{-1}\!\left\{\frac{s+1}{(s+1)^2+4}\right\} = e^{-t}\cos 2t$$

**문제 4.** 스프링-질량-감쇠기 시스템 $m\ddot{x} + c\dot{x} + kx = F(t)$에서 $m=1$, $c=2$, $k=5$, $F(t)=\delta(t)$(순간 충격), 초기 정지 상태($x(0)=\dot{x}(0)=0$)일 때의 응답을 구하여라.

> **풀이**
>
> 값을 대입하면 $\ddot{x} + 2\dot{x} + 5x = \delta(t)$. 초기 조건이 모두 0이므로 변환하면 도함수 공식의 초기값 항이 모두 사라진다:
>
> $$(s^2 + 2s + 5)X = \mathcal{L}\{\delta(t)\} = 1$$
>
> $$X = \frac{1}{s^2+2s+5} = \frac{1}{(s+1)^2+4}$$
>
> 표의 $\mathcal{L}\{e^{at}\sin\omega t\} = \dfrac{\omega}{(s-a)^2+\omega^2}$ 형태와 비교하면 $a=-1$, $\omega=2$이지만 분자에 $\omega=2$가 없으므로, $\dfrac{1}{2}$을 곱해 짜맞춘다:
>
> $$x(t) = \frac{1}{2}e^{-t}\sin 2t$$
>
> 이는 시간이 지남에 따라 진폭이 $e^{-t}$로 줄어드는 **감쇠 진동**이다 — 순간적인 충격(임펄스)을 받은 스프링-질량-감쇠기 시스템이 진동하며 서서히 멈추는 물리적 상황과 정확히 일치한다.
