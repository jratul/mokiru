그래프이론은 관계와 네트워크를 수학적으로 모델링하는 도구다. [중학 기하](/math/middle/geometry)에서 다룬 오일러의 공식 $V - E + F = 2$가 그래프이론의 핵심 결과 중 하나다. 그래프이론은 컴퓨터 과학의 알고리즘(최단경로, 네트워크 흐름, 스케줄링), [이산수학 조합론](/math/discrete/combinatorics), [AI 수학 최적화](/math/ai-math/optimization)에 광범위하게 적용된다.

## 그래프의 기본 개념

### 정의

**그래프** $G = (V, E)$: 꼭짓점(vertex) 집합 $V$와 간선(edge) 집합 $E \subseteq \binom{V}{2}$ (무향) 또는 $E \subseteq V \times V$ (유향).

**그래프의 종류**:

| 종류 | 설명 |
|------|------|
| **무향 그래프** | 간선에 방향 없음. $\{u, v\}$ |
| **유향 그래프(Digraph)** | 간선에 방향 있음. $(u, v)$ |
| **단순 그래프** | 루프·다중 간선 없음 |
| **가중 그래프** | 각 간선에 가중치 부여 |
| **이분 그래프** | 꼭짓점을 두 집합으로 분할, 간선은 집합 사이에만 |

**완전 그래프** $K_n$: $n$개의 꼭짓점 사이에 모든 간선 존재. 간선 수 $= \binom{n}{2}$.

### 차수

꼭짓점 $v$의 **차수** $\deg(v)$: $v$에 연결된 간선의 수.

**악수 정리(Handshaking Lemma)**:

$$
\sum_{v \in V} \deg(v) = 2|E|
$$

따라서 홀수 차수 꼭짓점의 수는 항상 짝수다.

유향 그래프에서: **진입차수**(in-degree)와 **진출차수**(out-degree) 구분.

$$
\sum_{v} \text{in-deg}(v) = \sum_{v} \text{out-deg}(v) = |E|
$$

### 동형(Isomorphism)

두 그래프 $G_1$, $G_2$가 **동형**이면 꼭짓점 집합 사이에 전단사 함수 $f$가 존재하여 간선 구조가 보존된다.

## 경로와 연결성

### 경로의 종류

- **보행(Walk)**: 꼭짓점과 간선을 번갈아 나열 (반복 허용)
- **트레일(Trail)**: 간선을 반복하지 않는 보행
- **경로(Path)**: 꼭짓점을 반복하지 않는 보행
- **순환(Cycle)**: 시작 꼭짓점과 끝 꼭짓점이 같은 경로

### 연결 그래프

무향 그래프에서 모든 두 꼭짓점 사이에 경로가 존재하면 **연결(connected)**이라 한다.

**연결 성분**: 최대 연결 부분 그래프.

유향 그래프에서:
- **강연결(strongly connected)**: 모든 두 꼭짓점 사이에 양방향 유향 경로 존재
- **약연결(weakly connected)**: 방향을 무시하면 연결

### 오일러 정리

**오일러 경로**: 모든 간선을 정확히 한 번 지나는 경로.  
**오일러 회로**: 시작 꼭짓점으로 돌아오는 오일러 경로.

**오일러 정리**: 연결 그래프에서
- 오일러 회로가 존재 $\iff$ 홀수 차수 꼭짓점의 수 = **0**
- 오일러 경로가 존재 $\iff$ 홀수 차수 꼭짓점의 수 = **2**

**역사**: 쾨니히스베르크의 7개 다리 문제(1736, 오일러)가 그래프이론의 시작.

## 해밀턴 경로

**해밀턴 경로**: 모든 꼭짓점을 정확히 한 번 지나는 경로.  
**해밀턴 회로**: 시작 꼭짓점으로 돌아오는 해밀턴 경로.

**판별**: NP-완전 문제 — 오일러 경로와 달리 효율적인 판별 알고리즘이 알려지지 않음.

**디랙 정리(Dirac's Theorem)**: $|V| = n \geq 3$이고 모든 $v$에 대해 $\deg(v) \geq n/2$이면 해밀턴 회로 존재.

**오레 정리(Ore's Theorem)**: 모든 비인접 쌍 $u, v$에 대해 $\deg(u) + \deg(v) \geq n$이면 해밀턴 회로 존재.

## 트리

### 정의와 성질

**트리(tree)**: 연결되고 순환이 없는 무향 그래프.

**동치 조건** (다음 중 하나면 나머지도 성립):
- 연결되고 순환 없음
- $|V| = n$이고 간선 수 $= n-1$
- 임의의 두 꼭짓점 사이에 경로가 유일
- 연결이지만 어느 간선을 하나 제거하면 비연결

**리프(leaf)**: 차수가 1인 꼭짓점. 모든 트리($|V| \geq 2$)는 적어도 두 개의 리프를 가진다.

### 루트 트리와 이진 트리

**루트 트리(rooted tree)**: 특정 꼭짓점을 루트로 지정한 트리. 부모/자식/형제 관계 정의.

**이진 트리(binary tree)**: 각 노드가 최대 2개의 자식을 가지는 루트 트리.

이진 탐색 트리, 힙, 표현식 트리 등 알고리즘에 광범위하게 쓰인다.

### 스패닝 트리와 최소 스패닝 트리

**스패닝 트리(spanning tree)**: 연결 그래프 $G$의 모든 꼭짓점을 포함하는 부분 트리.

**최소 스패닝 트리(MST)**: 가중 연결 그래프에서 총 가중치가 최소인 스패닝 트리.

**크루스칼 알고리즘(Kruskal)**: 가중치가 낮은 간선부터 순환이 생기지 않도록 추가. $O(E \log E)$.

**프림 알고리즘(Prim)**: 트리를 하나씩 키워 나가며 최소 가중치 간선을 추가. $O(E \log V)$.

## 그래프 색칠

**채색수 $\chi(G)$**: 인접한 꼭짓점에 같은 색을 주지 않고 색칠하는 데 필요한 최소 색의 수.

**4색 정리**: 모든 평면 그래프는 4가지 색으로 색칠 가능하다.

| 그래프 | $\chi$ |
|--------|-------|
| 이분 그래프 | $\leq 2$ |
| 홀 순환 $C_{2k+1}$ | 3 |
| 완전 그래프 $K_n$ | $n$ |

**이분 그래프 판별**: BFS로 2-색칠이 가능한지 확인. 가능하면 이분 그래프.

## 최단 경로

### 다익스트라 알고리즘 (Dijkstra)

가중치가 **비음수**인 유향 그래프에서 단일 출발점 최단 경로.

```
초기화: dist[s] = 0, 나머지 = ∞
우선순위 큐 사용
반복: 미방문 꼭짓점 중 dist 최소인 v 선택
      v의 이웃 w에 대해 dist[v] + w(v,w) < dist[w]이면 갱신
```

시간 복잡도: $O((V + E) \log V)$ (이진 힙 사용)

### 벨만-포드 알고리즘 (Bellman-Ford)

음수 가중치 허용. 음수 사이클 탐지 가능. $O(VE)$.

### 플로이드-워샬 알고리즘 (Floyd-Warshall)

모든 쌍 최단 경로. $O(V^3)$.

## 연습문제

**문제 1.** 꼭짓점이 5개이고 모든 꼭짓점의 차수가 2인 그래프의 간선 수를 구하여라.

> **풀이**
>
> 악수 정리: $\sum \deg(v) = 5 \times 2 = 10 = 2|E|$
>
> $|E| = 5$

---

**문제 2.** 꼭짓점이 $n$개인 트리에서 간선 수가 $n-1$임을 귀납법으로 증명하여라.

> **풀이**
>
> **기저** ($n=1$): 꼭짓점 1개, 간선 0개 = $1-1$ ✓
>
> **귀납**: $n$개의 꼭짓점을 가진 트리의 간선 수 $= n-1$이라 가정.
>
> $n+1$번째 꼭짓점을 리프로 추가하면 간선 1개 추가 → 간선 수 $= n = (n+1)-1$ ✓ ∎

---

**문제 3.** 다음 그래프가 오일러 회로를 가지는지 판별하여라: 꼭짓점 $\{A, B, C, D\}$, 간선 $\{AB, AC, AD, BC, BD, CD\}$.

> **풀이**
>
> 이 그래프는 $K_4$ (4꼭짓점 완전 그래프). 각 꼭짓점의 차수 $= 3$ (홀수).
>
> 홀수 차수 꼭짓점이 4개 → 오일러 회로와 경로 모두 **존재하지 않는다**.

---

**문제 4.** 가중 그래프에서 다음 간선들로 최소 스패닝 트리를 크루스칼 알고리즘으로 구하여라:

$AB(1), CD(2), BC(3), AC(4), BD(5)$

> **풀이**
>
> 가중치 순 정렬: $AB(1) \to CD(2) \to BC(3) \to \cdots$
>
> $AB$ 추가 (순환 없음): $\{AB\}$
>
> $CD$ 추가 (순환 없음): $\{AB, CD\}$
>
> $BC$ 추가 (순환 없음, A-B-C-D 연결): $\{AB, CD, BC\}$
>
> 꼭짓점 4개, 간선 3개 = $4-1$ → MST 완성. 총 가중치 $= 1+2+3 = 6$.
